# Fuentes clínicas permitidas para apoyo con IA

Esta carpeta conserva el registro humano de las fuentes que pueden sustentar un borrador de apoyo al profesional. El registro operativo equivalente se siembra en `clinical_guideline_sources` mediante la migración del objetivo 5. El workflow solo puede citar las claves que aparecen en ese registro.

Las fuentes se usan para organizar evidencia y preguntas de revisión. El borrador no diagnostica, no prescribe, no cambia medicamentos y no se envía al paciente. El profesional debe revisar el contexto, confirmar la fuente original y tomar la decisión clínica.

## Actualización

Cuando una guía cambie, agrega una nueva clave o actualiza su versión en la migración y en esta tabla. Conserva la URL, la organización, el año y el alcance. No borres una fuente que ya haya sido citada por un borrador histórico; márcala como inactiva en el registro si deja de estar vigente.
